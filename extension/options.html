Chrome-to-Terminal

Web → Terminal

Terminal

Auto-detect uses Bash/Zsh on macOS and Linux and PowerShell on Windows.

Native connector

This extension uses Chrome Native Messaging to launch the operating system terminal. Install the small Chrome-to-Terminal connector for your platform.

The browser extension does not upload your selected command to a Chrome-to-Terminal server. It sends the selected text to the locally installed connector.

Download Latest Connector from GitHub

The link always opens the current latest GitHub release, where you can choose the Linux, macOS or Windows connector for your computer.

Linux persistent terminal

On Linux, installing tmux enables one persistent Chrome-to-Terminal session, keeping previous commands, output and working directory available for later runs.

Safety

Commands execute with your normal operating-system user permissions. Only run commands you understand and trust.
