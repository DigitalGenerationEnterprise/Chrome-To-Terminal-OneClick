Run Anywhere

Web → Terminal

Terminal

Auto-detect uses Bash/Zsh on macOS and Linux and PowerShell on Windows.

Native connector

This extension uses Chrome Native Messaging to launch the operating system terminal. Install the small Run Anywhere connector for your platform.

The browser extension does not upload your selected command to a Run Anywhere server. It sends the selected text to the locally installed connector.

Safety

Commands execute with your normal operating-system user permissions. Only run commands you understand and trust.
